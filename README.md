# 🎯 Landing Page: RedStore

This project is an e-commerce landing page. I used HTML, CSS, and jQuery to build the page. It includes smooth transitions with CSS.

## 🌐 Live Demo

👉 Click [here](https://zahidbenu.github.io/redstore-landing-page/) to view the live project.

## 🚀 Features
- Header Scroll Fixed
- Fully Responsive
- Smooth hover transitions for interactive feedback
- Clear visual hierarchy for better readability
- Latest products
- Exclusive offers
- Brand logos
- Customer testimonials

## 🛠️ Technologies Used

- HTML5 – Website structure

- CSS3 – Styling and animations

- jQuery – Functional interactivity, UI manipulation and animations
